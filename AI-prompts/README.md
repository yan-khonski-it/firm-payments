# AI-prompts

This directory contains my chats and LLM discussions with different models to solve this task.

## Files format.
M: model. It can be one of these:

- CO = Claude Opus 5.5
- GPT: GPT (now Chat GPT does not allow to specify a model, it will route request to some model).
- SOL: GPT 5.6 Sol - used from github copilot.

Q: - my question or prompt

A: answer or summary of the answer.

MY: my comments or notes.
